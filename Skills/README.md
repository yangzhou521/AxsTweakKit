# Skills —— 可修改的技能包

这里的每个文件夹是一份 Markdown 技能，内容与设备上 Apelin 的技能库
（`~/Documents/wiki.qaq.apelin/skills/<name>/SKILL.md`）对应。放在仓库里是为了：

- 换设备、换越狱、重装后能直接带走，不用从聊天记录里捞；
- 能改：技能就是普通 Markdown，改完推上去，下次在别的机器上把文件夹拷回技能目录即可。

| 技能 | 讲什么 |
|---|---|
| [a11-roothide-ondevice](a11-roothide-ondevice/SKILL.md) | 这台 iPhone10,1（A11 / roothide）上的 deb 工作流：云编译双切片闭环、真根安装、重启进程读诊断、**一站一槽（Per-Site Original Slot）** 钩子修复法、故障速查 |

改技能的规矩：设备上那份和仓库这份要一致；只写实测成立的做法，实测数字要标清是哪台设备、哪次运行。
